
  # Modern Next.js Portfolio Website

  This is a code bundle for Modern Next.js Portfolio Website. The original project is available at https://www.figma.com/design/C7uzKV7T35T4iYdZqdS3NQ/Modern-Next.js-Portfolio-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Firebase setup

  Create a `.env` file with your Firebase project settings:

  ```
  VITE_FIREBASE_API_KEY=your_api_key
  VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
  VITE_FIREBASE_PROJECT_ID=your_project_id
  VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
  VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
  VITE_FIREBASE_APP_ID=your_app_id
  ```
